# PawRoute (Heaven redesign)

6-page static site: index, features, routes (Route Lab), pricing, story, contact.
No build step. Colours and fonts are tokens in `:root` of style.css. Nav and footer live in script.js (`pages` array).

Publish on GitHub Pages: put every file in the repo root, push, then Settings > Pages > Deploy from branch (main / root).

Before going live: replace the placeholder email, prices, persona quotes and the illustrative targets on the home page.
